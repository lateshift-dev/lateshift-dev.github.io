Order per API prüfen: Ist der Stop wirklich aktiv?

Notizen sagen „Stop aktiv“, der Broker sagt vielleicht etwas anderes. Typischer Fall: Eine Bracket-Order mit Tages-Gültigkeit verfällt über Nacht, die Position bleibt ungeschützt.

Ablauf in 4 Schritten

  1. Offene Orders abfragen (z. B. bei Alpaca /v2/orders?status=open).
  2. Prüfen: Gibt es ein Stop-Leg und ein Ziel-Leg? Gültigkeit GTC statt Day?
  3. Stückzahl der Order mit der Positionsgröße vergleichen.
  4. Fehlt etwas: sofort durch eine OCO-Order (Ziel + Stop, GTC) ersetzen.

Mache das nach jeder Order und zu Beginn jedes Handelstags. Ein fertiges Prüfskript findest du im Trade-Gatekeeper.

Keine Anlageberatung; Handel kann zu Verlusten führen.
